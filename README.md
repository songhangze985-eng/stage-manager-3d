# macOS 3D 舞台调度 (Stage Manager 3D)

> 灵感源自 macOS 台前调度与 Apple VisionOS 空间计算的纯原生 Web 3D 拟态多任务交互系统。  
> 零依赖（Zero-Dependency）、纯原生前端技术栈实现。

---

## 🌟 项目亮点与核心特性

### 1. 3D 向心空间调度（Hyperbolic Spatial Stage Engine）
- **立体向内双翼排布**：12 款拟真应用卡片分为左翼与右翼对称朝向，中央走廊自然留白、虚怀若谷，无任何多余分割线。
- **双曲函数数学纵深**：卡片在上下三层（Top / Middle / Bottom）依照严格的向心双曲数学曲线排列，由远及近从小到大（远端内侧 83% 紧靠中心走廊，近端外侧 104% 饱满展开）。
- **下层卡片悬停平铺**：鼠标悬停位于底层的卡片时，触发向上提拉、摆正倾角并放大平铺交互（`translate3d(0, -68px, 280px) rotate(0deg) scale(1.22)`）。
- **3D 空间全键盘方向键导航**：调度模式下支持 `↑` `↓` `←` `→` 方向键在 3×4 空间矩阵中顺畅游走，聚焦卡片拥有明亮的青蓝光晕并向前浮起（`.spatial-focus`），回车键秒速激活。

### 2. 沉浸式影院级纯色消隐
- 触发调度模式瞬间，桌面壁纸退散渐隐，替换为深邃纯黑哑光背景。
- 右下角感应区在 3D 模式下自动隐藏并阻断交互，杜绝遮挡与误触。

### 3. 高拟真双层毛玻璃顶栏（High-End Glassmorphism）
- **空间调度水晶徽标**：采用免费商用艺术字体（站酷快乐体、站酷高端黄油体）修饰，彰显潮流科技质感。
- **实时过滤搜索框**：支持输入关键词实时模糊搜索过滤多任务应用胶囊，按 `Enter` 键直接唤起首个匹配项。
- **多任务分区频道栏（承接原侧边栏功能）**：12 款应用胶囊紧凑横向排布，悬浮任意胶囊即可向下弹出高阶深色毛玻璃小窗动态微缩预览（Popover），点击即可平滑切换桌面主窗口。

### 4. 热门 UI 组件：明暗微动质感切换胶囊（Day / Night Switch）
- **流体微动效滑块**：
  - **暗夜流光（Dark Glass）**：深邃星空渐变滑轨，点缀闪烁微星与深蓝弯月，搭配深曜石毛玻璃。
  - **明昼白璃（Light Glass）**：晨曦金阳暖色滑轨，滑块弹性滑移绽放金色暖阳，界面瞬间切换为通透晶莹的白昼霜璃风格，卡片与文字全自动自适应高对比度。
- 全界面具备物理级内嵌边缘反光（`inset 0 1.5px 1px rgba(255, 255, 255, 0.45)`）与高饱和度模糊（`blur(40px) saturate(210%)`）。

### 5. 原生级 macOS 窗口与触觉音效
- **交通灯微拟物控制**：红点/黄点支持微动收起至侧边栏，绿点支持桌面全屏铺满/常规窗口无缝缩放，悬停浮现 `×` `−` `+` 符号指示。
- **Web Audio API 程序化音频合成**：内置气泡轻触（Pop）与气流穿梭（Swoosh）音效，无需下载外部音频资源。

## 🎮 交互指南与快捷键

| 操作 / 快捷键 | 功能描述 |
| :--- | :--- |
| **鼠标滑入右下角** | 弹出半贴身 3D 倾斜方块，点击即刻进入 3D 舞台调度 |
| **点击 3D 舞台任意卡片** | 该卡片飞扑镜头放大，退出调度并作为桌面当前主窗口打开 |
| **`ESC` 键** | 退出 3D 舞台调度，返回桌面工作区 |
| **`↑` `↓` `←` `→` 方向键** | 3D 调度模式下在 12 款应用卡片的空间矩阵中导航 |
| **`Enter` / `Space` 键** | 激活当前处于聚焦高亮态的卡片 |
| **`Cmd + Space` / `Alt + Space`** | 桌面模式下快捷唤出/切换 3D 舞台调度 |
| **顶部明暗开关** | 实时在深邃暗夜毛玻璃与纯净白昼霜璃主题间切换 |
| **窗口红/黄/绿点** | 最小化收起窗口 / 铺满全桌面切换 |

## 🚀 快速启动

本项目为纯前端静态工程，无需安装任何 Node.js 依赖或打包构建：

### 方式 1：静态服务器启动（推荐）
```bash
# Python 3
python3 -m http.server 8080

# 或使用 Node.js npx serve
npx serve .
```
启动后在现代浏览器（Chrome / Safari / Edge / Firefox）中访问 `http://localhost:8080/` 即可体验。

### 方式 2：直接本地打开
双击 `index.html` 或在浏览器中直接打开文件。

## 🛠️ 技术实现细节

1. **CSS 3D 透视矩阵**：
   - 舞台视口基于 `perspective: 1500px` 与 `transform-style: preserve-3d` 构建真实物理景深。
   - 所有内侧卡片数学纵深设定为正向 $Z \ge 28\text{px}$，彻底杜绝负深度穿透导致子元素无法点击的浏览器分层 bug。
2. **数学双曲曲线（Hyperbolic Spatial Curve）**：
   - 依据卡片在左右翼的位置 $s \in \{-1, +1\}$、上下层级 $t \in \{-1, 0, 1\}$ 与归一化向心参数 $u \in [0, 1]$，计算出旋转切角 $\theta$、俯仰角 $\text{rotX}$ 与缩放比率 $\text{scale}$。
3. **免费商用艺术字体支持**：
   - 引用 Google Fonts：`ZCOOL KuaiLe`（站酷快乐体）与 `ZCOOL QingKe HuangYou`（站酷高端黄油体），免授权开源商用。
